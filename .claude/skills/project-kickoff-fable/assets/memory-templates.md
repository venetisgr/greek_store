# Memory file skeletons

Create these under `docs/` during Phase 2. Seed STATE.md's "Now" and "Next" from the approved roadmap's first phase so the next session can start working immediately.

## docs/STATE.md

```
# STATE

## Now
[The single task in progress and the current approach, 1–3 lines.]

## Next
1. [Ordered items for the current roadmap phase]

## Decisions
<!-- One dated line per decision, newest last. -->
- YYYY-MM-DD: [Decision and one-line reason.]
```

## docs/LESSONS.md

```
# LESSONS

<!-- One lesson per entry, one-line summary first. Corrections and
     confirmed approaches both. Don't duplicate what the repo or chat
     history already records; update entries rather than adding twins;
     remove entries proven wrong. Check before non-trivial attempts. -->

## [One-line summary of the lesson]
- What happened: [attempt or discovery]
- Why it mattered: [root cause / why this changes future behavior]
- Do instead: [the approach to use going forward]
```

## docs/IDEAS.md

```
# IDEAS

<!-- Parking lot. Add freely during work; act on nothing here unless the
     user promotes it into ROADMAP.md. One line each, newest last. -->

- [Idea, and why it seemed worth noting]
```
